# Skjæringspunktet – Portfolio Website

Portfolio website for the firm **Skjæringspunktet**.

## Structure

```
├── index.html          # Main entry point
├── css/
│   └── styles.css      # Global styles
├── js/
│   └── main.js         # JavaScript
├── assets/
│   ├── images/         # Image assets
│   └── fonts/          # Custom fonts
└── README.md
```

## Getting Started

Open `index.html` in a browser, or serve locally with any static file server:

```bash
npx serve .
# or
python3 -m http.server
```
